# Frontend - [Tên Dự Án / Website Bán Quần Áo]

Đây là thư mục chứa mã nguồn Frontend cho hệ thống website thương mại điện tử bán quần áo. Dự án cung cấp giao diện cho khách hàng (xem sản phẩm, thêm vào giỏ hàng, thanh toán) và được xây dựng bằng [ Next.js ].

---

## Yêu cầu hệ thống (Prerequisites)

Để chạy và phát triển dự án trên máy cá nhân, bạn cần cài đặt sẵn các công cụ sau:

- **Node.js**: Phiên bản `v16.x` hoặc cao hơn.
- **Package Manager**: `npm` (thường đi kèm Node.js) hoặc `yarn`.
- **Trình duyệt**: Khuyến nghị Google Chrome hoặc Firefox để test và debug tốt nhất.

---

## Hướng dẫn cài đặt (Installation)

Thực hiện các bước sau để thiết lập dự án trên máy của bạn:

**Bước 1:** Mở terminal, di chuyển vào thư mục frontend:

```bash
cd web
```

**Bước 2:** Cài đặt các thư viện và dependencies cần thiết:

```bash
npm install
```

**Bước 3**: Cấu hình biến môi trường:

# URL kết nối tới Backend API

### Khởi động server dev để xem giao diện:

```bash
npm run dev
```

## Hướng dẫn chạy Test (Testing)

**1. Chạy Unit Test và Integration Test**
Chạy toàn bộ test:
